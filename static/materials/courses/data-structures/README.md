# Data Structures course materials

The course page is `content/teaching/courses/data-structures.md`. Files in this
folder are Hugo source assets, served from `/materials/courses/data-structures/`.
Add future uploads here, not to the generated `public/` directory.

## Student-facing organization

- `materials/notes/`: pointer, linked-list, and stack/queue chapters; the
  `Data-Structures-Before-Code.pdf` cheatsheet is listed separately as reference.
- `materials/presentations/`: current lecture PDFs and editable PowerPoint files.
- `materials/practice-problems/`: array practice and Code Quest I.
- `materials/code/`: revised queue examples and traces.
- `materials/codebook/`: the Dragon Scroll PDF, browser edition, and original ZIP.

The cheatsheet and codebook are **quick reference only, not learning material**.
Keep that notice immediately above their links. Learning begins with the stories,
predictions, classroom discussion, and the student's own traces and code.
The browser codebook also carries the notice for readers arriving directly.
