# Teaching materials

Files placed under this directory are served publicly by Hugo.

For example:

```text
static/materials/lecture-notes/example.pdf
```

will be available at:

```text
/materials/lecture-notes/example.pdf
```

Use clear lowercase filenames with hyphens, for example:

```text
graph-traversal.pdf
dynamic-programming-slides.pdf
chapter-01-introduction.pdf
```
