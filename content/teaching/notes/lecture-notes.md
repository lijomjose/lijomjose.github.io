# Lecture Notes

This page collects lecture notes prepared for classroom teaching and student reference.

## Available notes

Add PDF notes under:

```text
static/materials/lecture-notes/
```

Then link them here using paths such as:

```markdown
- [Asymptotic Notation](/materials/lecture-notes/asymptotic-notation.pdf)
- [Graph Traversal](/materials/lecture-notes/graph-traversal.pdf)
```

## Suggested organization

For each note, include:

- topic
- course, if applicable
- short description
- file link
- draft/final status
