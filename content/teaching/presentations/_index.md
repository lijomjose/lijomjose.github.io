# Presentations

This page collects classroom slides, seminar presentations, and short teaching decks.

## Available presentations

Add slides under:

```text
static/materials/presentations/
```

Then link them here using paths such as:

```markdown
- [Introduction to Graph Theory](/materials/presentations/introduction-to-graph-theory.pdf)
- [Dynamic Programming](/materials/presentations/dynamic-programming.pdf)
```

PDF is usually the safest format for browser viewing. Source files such as `.pptx`, `.key`, or `.odp` can also be linked if you want students to download them.
